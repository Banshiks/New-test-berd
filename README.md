# Вместе до финиша 💕

Кооперативный 2D платформер для двух игроков онлайн.

## Стек
- **Фронтенд**: React + Canvas API (Vite)
- **Бэкенд**: Node.js + Express + WebSocket (`ws`)

## Запуск локально

```bash
# Установить зависимости
npm run install:all

# Запустить в режиме разработки (два процесса)
npm run dev
```

Открой `http://localhost:5173` на обоих компьютерах.

> По умолчанию клиент подключается к WebSocket-серверу по адресу текущего хоста.  
> В режиме разработки задай переменную: `VITE_WS_URL=ws://localhost:3001`

## Продакшн-деплой

```bash
npm run build   # собирает клиент в client/dist
npm start       # запускает сервер, который раздаёт и фронт, и WS
```

## Как играть

1. Один игрок нажимает **Создать комнату** и видит 4-буквенный код.
2. Второй игрок нажимает **Войти по коду** и вводит код.
3. Оба добираются до флажка на каждом из 3 уровней.

**Управление**: `WASD` или Стрелки | Прыжок: `W` / `↑` / `Space`

| Уровень | Тема | Фишка |
|---------|------|-------|
| 1 — Знакомство | Дневное небо | Простые платформы |
| 2 — Путь к сердцу | Закат | Зигзагообразный маршрут |
| 3 — Вместе навсегда | Ночь | Игроки стартуют с разных сторон и встречаются наверху |
